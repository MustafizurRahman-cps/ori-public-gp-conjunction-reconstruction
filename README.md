# Availability-aware LEO conjunction reconstruction: reproducibility software

Associated research manuscript:

> Availability-Aware Framework for Reconstructing Known LEO Conjunctions from Public GP Histories: Sequential Stability and Error-Envelope Coverage

## Scope
This repository is a **research software and aggregate-evidence release**.
It includes the unchanged frozen scientific Python scripts, the validated environment lock,
selected methodological specifications, aggregate scientific summaries, and a sealed author-side
clean-replay comparison. It does not include all historical governance records or event-level datasets.

The method studies **externally specified known object pairs**. GP/GP_HISTORY publications
are admissible by `CREATION_DATE <= replay_time`. Candidate geometry is generated by SGP4/WGS-72
without reference values. Reference TCA is used for retrospective scheduling, necessary temporal-support
filtering and postcandidate association; reference miss distance enters only conditional error evaluation.
This package does not estimate collision probability or operational warning capability.

## Reproduction modes
1. **Software inspection and summary verification:** inspect `scripts/`, `results/`,
   and the included static controls; validate file hashes using
   `python tools/preflight_public_release.py`.
2. **Numerical and analytical reruns:** require correctly prepared historical source GP/GP_HISTORY
   snapshots and externally obtained reference inputs. The provider data and local work-state databases
   are not redistributed. Acquisition at a later time may not reproduce an identical historical snapshot.
3. **Historical Mode A clean replay:** previously verified by the authors; the comparison evidence is
   provided in `docs/release/mode_a_evidence/final_comparison.json`. This subset is **not** a
   standalone one-command clean-replay package: original source-history inputs, selected
   registers/controls, and private staging evidence are outside its scope.

**Important:** Aggregate result files do not allow recomputation of all event-level bootstrap
intervals or figure curves without source or derived event-level observations. No claim of fully
self-contained independent reconstruction is made.
