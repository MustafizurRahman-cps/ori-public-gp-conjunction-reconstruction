# Data provenance, rights, and publication boundaries

This software repository provides source code, methodological controls, and
scientific derived outputs for retrospective, known-pair public-GP reconstruction.
Raw authenticated source-history downloads, local work-state databases, and
account credentials are not included.

- **Space-Track GP / GP_HISTORY:** the original provider and account terms
  apply. Space-Track documentation describes an express redistribution approval
  for specified basic SSA products, conditional on source attribution. This
  repository does not assume that such language conclusively covers every
  historical publication metadata field or all downstream event-level tables.
  Release of included derived rows must be approved within the authors' rights
  and the applicable provider conditions. Source: https://www.space-track.org/documentation
- **NOAA TraCSS verification dataset:** the Office of Space Commerce describes
  its published verification dataset as CC0-1.0 (full/open use and dissemination).
  Attribution to NOAA/TraCSS and the specific source version remains appropriate.
  Source: https://space.commerce.gov/tracss-publishes-dataset-for-conjunction-assessment-verification/
- **Original project code:** BSD-3-Clause, as set out in the root LICENSE.
- **Author-owned eligible non-code materials:** CC BY 4.0 as delimited in
  LICENSE_SCOPE.md. Third-party rights are not overwritten.

Detailed event-level tables containing NORAD catalog IDs, Space-Track publication/GP identifiers, reference-event IDs, timestamps and reconstructed geometry are intentionally excluded from this curated public release. The authors retain them privately; upstream and institutional redistribution conditions must be assessed independently before any future public release.

**Publication prerequisite:** confirm legal/institutional rights over every
included derived table and authorship/copyright metadata before making this
repository public or issuing a persistent DOI. This document is not legal advice.
