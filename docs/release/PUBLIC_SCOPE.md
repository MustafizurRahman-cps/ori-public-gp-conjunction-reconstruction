# Release scope and exclusions

This is a **curated research software release** prepared from the verified sanitized internal candidate.
It is narrower than the authors' full 299-file research release candidate, which remains private.

Included: 81 Python source files, selected frozen
methodological controls, dependencies, code licenses, citation metadata, preflight audit utility,
one clean-replay summary, and compact frozen aggregate metrics supporting the manuscript.

Excluded: source data and original account-specific downloads, raw GP_HISTORY, local state databases,
detailed event-level reconstruction/update tables, full internal administrative governance records,
authentication material and local private workflows.

This subset is suitable for software citation and transparent disclosure of core methods but is **not**
a complete turnkey reconstruction: original input archives, reference events and certain historical
registers must be reacquired or recreated under source-provider terms.

To regenerate all manuscript statistical quantities exactly, a researcher must supply matching
historical data, permitted internal supporting inputs, and use the documented fixed parameters;
reacquired histories may differ from the author's archived snapshot. Published aggregate summaries
are not substitutes for the underlying event-level datasets in independent statistical recomputation.

The authors must check final citation metadata, permissions for their code and supporting documentation,
and the applicable repository and source-provider requirements before public release. Do not present this subset as
independently rerun by third parties.
